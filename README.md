# 🌳 Yggdra Tech

Plataforma digital da **Yggdra Tech**, focada em desenvolvimento de software, soluções escaláveis e experiências modernas.

---

## 💡 Sobre o projeto

Este projeto representa a presença digital da Yggdra Tech, combinando:

- Landing page institucional moderna
- Interface interativa com animações avançadas
- Estrutura preparada para integração com sistemas (SaaS)
- Design focado em performance e experiência do usuário

---

## ⚙️ Tecnologias utilizadas

- HTML5
- CSS3 (animações, responsividade e UI moderna)
- JavaScript
- Node.js (estrutura backend)
- Font Awesome (ícones)

---

## 🎨 Features

- 🔥 Logo interativo com efeito neon
- ⚡ Navbar com animação de energia (inspirado em Yggdrasil)
- 🎯 Seção de serviços com design moderno
- 💬 Chatbot integrado
- 🌐 Links sociais interativos com animação
- 📱 Layout responsivo
